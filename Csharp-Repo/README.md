# ▶️ How To Run Projects

## Using .NET CLI

Navigate to a project folder:

```bash
cd ConsoleApp10
```

Run the application:

```bash
dotnet run
```

---

## Using Visual Studio

1. Open the repository
2. Select a project folder
3. Open the `.sln` or `.csproj` file
4. Click **Run / Start**
