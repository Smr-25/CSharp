## ▶️ How to Run
1. Open the repository in **Visual Studio** (or **Rider / VS Code** with .NET).
2. Choose a project folder (e.g., `ConsoleApp10`).
3. Open the `.sln` file (if included) or the project (`.csproj`).
4. Run:
   - Visual Studio: **Start**
   - CLI:

```bash
cd <ProjectFolder>
dotnet run
```
